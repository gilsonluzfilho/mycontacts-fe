# MyContacts — Frontend

Aplicação web desenvolvida com **React** para gerenciamento de usuários, contatos e suas respectivas categorias, integrada à API REST do projeto.

## Tecnologias

* React
* React Router
* Styled-components

## Funcionalidades

* Gerenciamento de contatos
* Gerenciamento de categorias
* Organização dos contatos por categoria
* Integração com a API REST

## Backend

Este projeto utiliza uma API desenvolvida com Node.js e Express:

👉 [MyContacts — API](https://github.com/gilsonluzfilho/mycontacts-api)
